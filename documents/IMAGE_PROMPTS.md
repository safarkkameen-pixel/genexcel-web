# GenExcel.ai Website Image Prompts

## Overview

This document contains detailed prompts for generating all visual assets needed for the GenExcel.ai website. Each prompt is designed for AI image generation tools (Midjourney, DALL-E, Stable Diffusion, etc.) and includes specifications for style, dimensions, and usage context.

**Style Guidelines:**
- Modern, clean, healthcare-focused aesthetic
- Primary colors: Blue (#2563EB), Cyan (#06B6D4), Sky Blue (#0EA5E9)
- Soft gradients and rounded shapes
- Diverse representation (children of different ethnicities)
- Age range focus: 4-18 years
- Professional yet warm and approachable
- No stock photo feel - custom illustration style preferred

## Image Generation Notes

### Style Consistency Guidelines

1. **Color Palette:** Always use the GenExcel blue (#2563EB), cyan (#06B6D4), and sky blue (#0EA5E9) as primary colors
2. **Illustration Style:** Modern flat illustration with soft gradients, similar to Notion, Linear, or Stripe marketing
3. **Human Representation:** Diverse ethnicities with focus on Indian market (40% Indian, 30% other Asian, 20% Caucasian, 10% African/Other)
4. **Age Range:** Children should be between 4-18 years, clearly distinguishable by size and features
5. **Medical Imagery:** Friendly and non-clinical; avoid sterile hospital aesthetics
6. **Technology:** Modern devices (current iPhone/iPad designs), clean interfaces
7. **Mood:** Optimistic, empowering, trustworthy, warm, and approachable

### File Format Requirements

- **Icons:** SVG preferred, PNG with transparency as fallback
- **Hero Images:** WebP with PNG fallback, multiple resolutions (1x, 2x, 3x)
- **Social Media:** JPG for broad compatibility
- **Print/PDF:** High-resolution PNG (300dpi minimum)

### Accessibility Considerations

- Ensure sufficient contrast in all images
